1

POST /process-query

Frontend sends query, user_id, location, session_id. Backend wraps in AgentState and invokes graph with thread_id=user_id.

2

Supervisor Routes

Priority checks: sexual_offense keywords → question_processor intake flow → pending_questions → nodal consent → lawyer/sahayak intent → LLM one-word classification.

3

Specialist Agent

Cyber / Civil / Domestic / Scam / Document fetches RAG legal context, generates markdown advice with classification tags [Cognizable][Complex_MLAT][Fraud_Under_10k].

4

report_generator Hub

LLM parses classification tags → builds structured_report JSON. Decides routing: high risk → legal_moderator, low/small → nodal_guide, medium → question_processor, sexual → sexual_offense.

5

question_processor (multi-turn)

Asks 2-3 follow-up questions one at a time. Each answer collected into collected_answers. Supervisor re-routes here each turn while pending_questions not exhausted.

6

Terminal Handoff

sahayak saves to DB + fetches profiles → show_sahayak_panel. lawyer_forwarder → recommended_lawyers. legal_moderator → Supabase intervention queue + WS broadcast. nodal_guide → Gram Nyayalaya officer profile.

7

API Response

Returns final_response, structured_report, suggested_actions, trace to frontend. Frontend reads panel flags (show_sahayak_panel, show_lawyer_panel, etc.) to render UI.
